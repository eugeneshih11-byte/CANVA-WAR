# Game01 Project Guide

Game01 is a learning project for building a simple 2D browser game.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- HTML Canvas

## Development Guidelines

- Develop the game incrementally.
- Only implement the feature explicitly requested in the current task.
- Do not add unrelated or future mechanics.
- Keep code minimal and easy to understand.
- After making changes, explain important new code and concepts.

## Completed: v0.1

- Canvas setup
- Player rendering
- Game loop
- WASD input
- Simultaneous key input
- Normalized movement
- Delta-time-based movement
- Canvas boundary constraints
