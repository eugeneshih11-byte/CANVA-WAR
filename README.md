# Game01

Game01 is a simple 2D browser game learning project built with HTML, CSS, vanilla JavaScript, and HTML Canvas.

## Controls

- W: Move up
- A: Move left
- S: Move down
- D: Move right

## Completed Features

- 800 × 600 canvas setup
- Player rendering
- Game loop
- WASD movement with simultaneous key input
- Normalized diagonal movement
- Delta-time-based movement
- Canvas boundary constraints

Current completed version: **v0.1**.
